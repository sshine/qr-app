# End-to-end tests

Playwright, driving a real browser against a real server. Everything comes from
the flake. There is no `package.json`, no lockfile and no install step, because
nixpkgs' `playwright-test` wrapper puts its own `node_modules` on `NODE_PATH` and
its browsers in the Nix store.

```
just e2e                      # the whole suite
just e2e -g "log in"          # one test
just e2e --headed --ui        # needs `nix develop .#headed`
playwright show-report e2e/playwright-report
```

Playwright starts the server itself, through the `webServer` block in
`playwright.config.ts`. Run `just serve-e2e` by hand only to poke at a throwaway
instance. It listens on __E2E_PORT__, away from the port the dev server uses, so
a test run cannot mutate state being clicked through by hand.

## Browsers

The default devshell carries only `chromium_headless_shell`, which is what
Playwright reaches for in headless runs anyway, and which the config pins as its
channel. Headed Chromium is another 574 MB and only interactive debugging wants
it, so it lives behind `nix develop .#headed`, which sets `PW_HEADED`, unpinning
the channel and letting `--headed`, `--ui` and `codegen` work.

## Agents

`.claude/agents/` holds a planner, a generator and a healer, generated by
`playwright init-agents --loop=claude`. They drive the browser through the test
runner's own MCP server (`playwright run-test-mcp-server`, wired up in
`.mcp.json`) and run on whatever Claude Code session is already authenticated.
No API key is involved.

Regenerate them after a Playwright upgrade, since the tool list changes:

```
playwright init-agents --loop=claude -c e2e/playwright.config.ts
```

The separate `playwright-mcp` package is deliberately unused: it resolves its
browser as "chrome-for-testing" and will not fall back to the headless shell, so
adopting it would drag headed Chromium back into the default closure.

Plans the planner writes belong in `e2e/specs/`. Ask for them there explicitly,
because the agent definitions' examples say a bare `specs/`.

## Conventions

`.claude/skills/playwright-tests/SKILL.md`. Read it before adding a test.
